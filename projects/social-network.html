Social Network Simulation

year
2025
stack
C++, Visual Studio 2022 (MSVC)
context
Algorithms and Data Structures course
links
source

A simplified social network modelled as a graph: users are nodes, friendships are edges.

What it does

  • Add and remove users.
  • Add and remove friendships between users.
  • Traverse the network with BFS and DFS.
  • Find the shortest path between two users.
  • Print the network and its adjacency information.

What I learned

Choosing a graph representation and seeing how that choice shapes every operation on top of it: adding a user, removing one cleanly, and searching the network efficiently.
